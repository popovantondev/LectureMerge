# Работа с проектом

Прочитайте [правила версий](docs/VERSIONING.md), затем проверьте `git status`.
Для доработки создайте отдельную ветку. Не включайте чужие изменения в коммит.

Код интерфейса находится в Sources/App.swift, очередь — QueueModel.swift,
медиа — Core.swift и Audio.swift, проекты — Project.swift.
Пользовательские надписи пишутся по-русски. Комментарии и технические имена
могут быть английскими. Предпочитайте небольшие целевые изменения.

Изменения обработки медиа проверяйте соответствующим интеграционным сценарием:
длительность, AAC priming, порядок языков/default, отсутствие перезаписи,
отмена и совпадение пакетов в режиме copy. Для изменений интерфейса проверяйте
живое окно. Не запускайте повторно весь набор без конкретной причины.

Команды описаны в [BUILD.md](docs/BUILD.md). В описании изменения укажите
наблюдаемое поведение, сделанное исправление и выполненные проверки.
Перед выпуском обновите CHANGELOG.md. Личные медиафайлы и журналы не добавляйте.
