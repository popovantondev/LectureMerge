# Сторонние компоненты

| Компонент | Версия | Назначение | Лицензия |
|---|---|---|---|
| FFmpeg / FFprobe | 9.0.1 | Анализ, видео, звук, контейнеры | LGPL 2.1+ для этой сборки |
| LAME | 4.0 | MP3 | LGPL, см. vendor/LAME-COPYING |
| pkgconf | 2.5.1 | Только инструмент сборки | Тексты лицензий внутри исходного архива |
| Apple AppKit / SwiftUI / VideoToolbox / AudioToolbox | Системные | Интерфейс и аппаратное кодирование | Компоненты macOS |
| SF Symbols | Системный | play.rectangle.on.rectangle.fill | Условия Apple для SF Symbols |

Официальные адреса архивов и их зафиксированные SHA-256:
[vendor/dependencies.json](vendor/dependencies.json).
Сведения о сборке и лицензиях: [vendor/NOTICE.md](vendor/NOTICE.md).
Неизменённые архивы исходников кодеков и тексты лицензий включаются в `.app`.
