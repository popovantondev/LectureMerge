# Устройство LectureMerge

Нативное приложение AppKit + SwiftUI, без веб-сервера и внешних API.

| Файл | Ответственность |
|---|---|
| Sources/App.swift | Окно, меню, строки очереди и настройки |
| Sources/QueueModel.swift | Состояние интерфейса, импорт, очередь, параллельность и отмена |
| Sources/Core.swift | Анализ FFprobe, подбор комплекта, MP4, субтитры, проверка и публикация |
| Sources/Audio.swift | Аудиопрофили, AAC/MP3, общий резерв места на диске |
| Sources/Project.swift | Формат JSON-проекта и восстановление выбранных путей |

Сначала FFprobe читает потоки и временную шкалу. Matcher подбирает компоненты
по полному имени и проверяет комплект. ExportPlan/AudioPlan выбирают параметры
FFmpeg. Неподдерживаемые сочетания показываются пользователю до обработки.

Каждый активный процесс имеет собственный Cancellation. Swift task group
запускает до четырёх заданий. MainActor обновляет окно; долгие процессы работают
в отдельных задачах. Общий резерв диска учитывает все активные результаты.

FFmpeg пишет временный файл в папке назначения. После проверки потоков,
языков/default, длительности и декодирования образцов выполняется атомарная
публикация. RENAME_EXCL защищает режим копий от конкурентной перезаписи.

RU AAC-LC в M4A копируется с сохранением временной шкалы и AAC priming;
несовместимый звук кодируется. Нет `-shortest`: короткая речь/субтитры не
отрезают видео. При существенном расхождении длительностей нужен ручной разбор.

Проект хранит ссылки на локальные файлы, не вкладывает медиа. При восстановлении
завершённый результат проверяется; разрешение заменять файлы не сохраняется.

Приложение отдельно от SRT Voiceover. Оно не синтезирует и не переводит речь.
HDR/HEVC-видеокодирование, улучшение и продолжение с середины файла не реализованы.
