# Основная папка проекта

С 3 сентября 2026 года разработка ведётся в **Dist/lecture_merge**.
Это копия рабочей версии 2.0 с оформлением репозитория и релизов.
Старая папка **Оля лекции транскрипция FFMPEG** с версиями 1.0 и 2.0 сохранена.

Перенесены исходники, тесты, иконка, лицензии и локальные зависимости.
Не переносились реальные лекции, WAV/M4A/SRT, старые журналы, кэши сборки
и гигабайты тестовых результатов. Историческое ТЗ сохранено отдельно;
личные абсолютные пути в его примерах заменены условными.

Приложение в `dist/v2.0.0` самодостаточно: FFmpeg и FFprobe находятся внутри.
SRT Озвучка и её настройки не менялись. Для её M4A новый путь сборщика
ничего не меняет: звук выбирается рядом с видео или вручную.

Сохранённые `.olyalecture` можно открыть здесь, если исходные медиафайлы остаются
по прежним путям. Состояние очереди не переносится автоматически между окнами.
Bundle identifier и каталог журналов сохраняются для совместимости версии 2.
Если старая версия 2 уже открыта, сначала завершите её вручную, затем откройте
новую. Ярлык Dock автоматически не переназначается.

Дальнейшие изменения выполняются в этом репозитории и выпускаются под новым
номером по [VERSIONING.md](VERSIONING.md).
