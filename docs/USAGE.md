# LectureMerge 2.1.0 — руководство пользователя

Отдельная новая программа для macOS 14+ на Apple Silicon.
Запуск локальной сборки: **dist → v2.1.0 → Сборка лекций 2.app**. FFmpeg и MP3-кодек уже внутри.
Программу можно перенести целиком в удобную папку. Интернет и API не нужны.
Прежние программы остаются в исходной папке; см. [MIGRATION.md](MIGRATION.md).

## Быстрый запуск

1. Добавьте папку с лекциями или отдельные видео/аудиофайлы, либо перетащите их в окно.
2. Выберите строку. Кнопка **Открыть исходник** находится прямо под её названием.
3. Справа проверьте подобранные файлы и выберите **Видео MP4** либо **Только звук**.
4. Настройки каждой строки независимы. Общие настройки применяются кнопкой
   **Применить ко всей очереди**.
5. Укажите папку результата. По умолчанию — **Готовое** рядом с исходником.
6. Сначала сделайте **Тест 30 секунд**, затем запустите очередь.

Удаление строки: Backspace, Delete, корзина или правая кнопка мыши →
**Удалить из очереди**. **Очистить очередь** убирает весь список.
Исходники и уже готовые результаты при этом остаются на диске.

## Видео и разрешение

Доступны **144, 240, 360, 480, 720, 1080, 1440 (QHD), 2160p (4K)**.
Пропорции и частота кадров сохраняются. Увеличение выше исходного разрешения
разрешается отдельным переключателем и не восстанавливает детали.

**Без перекодирования** копирует готовое совместимое H.264 8-бит 4:2:0:
качество и битрейт видео не меняются. Несовместимый кодек потребует другого режима.
**Исходное разрешение** сохраняет размер кадра; совместимое видео тоже копируется,
пока не включено **Сжать заново даже при том же разрешении**. С этим переключателем
видео кодируется заново, а размер кадра остаётся прежним.

Для изменения разрешения/сжатия используется аппаратный H.264 Apple VideoToolbox.
**Компактно / Баланс / Чётче** управляют битрейтом. Для «Баланс» по высотам выше:
180 / 450 / 800 / 1300 / 2400 / 4500 / 8000 / 16000 кбит/с.
Множители остальных режимов — 0,65 и 1,5. Размер результата приблизительный.
HDR автоматически не преобразуется; CPU/HEVC-видеокодирование не включено.

## AAC из программы озвучки — прямо в MP4

Пример комплекта:

```text
03_01_821049013_720p.mp4
03_01_821049013_720p.ru.siri.voice.m4a
03_01_821049013_720p.ru.srt
03_01_821049013_720p.srt
```

Поддерживаются MP4/MKV; озвучка WAV/M4A/AAC. Для автоматического подбора
поддержаны суффиксы `.ru.siri.voice`, `.ru.voice`, `.ru`. Если рядом одновременно
WAV и M4A, выберите нужный вариант справа: программа не угадывает.
Любой компонент можно указать вручную. Субтитры нужны в UTF-8.

Включённое по умолчанию **Копировать готовый RU AAC-LC без перекодирования**
использует AAC-LC из M4A/MP4 с одной дорожкой, моно или стерео, без потери качества.
Частота, каналы, битрейт, таймкоды и AAC priming сохраняются. Формат новой
«SRT Озвучки» — AAC-LC, 128 кбит/с, 48 кГц, стерео в M4A — подходит.

Озвучка может закончиться раньше видео, по последнему русскому субтитру.
В режиме копирования она заканчивается в исходной позиции, а видео продолжается
полностью без русской речи на оставшемся участке. `-shortest` не используется.
Если длительность озвучки совпадает с концом RU SRT с допуском 0,5 с, такой
комплект разрешён независимо от длины тихого хвоста видео. Речь не растягивается.
Если короткий звук не совпадает с SRT, запуск блокируется для проверки.
Звук длиннее видео также блокируется: последние слова могли бы обрезаться.

WAV и несовместимый звук кодируются в AAC-LC 128 кбит/с, 48 кГц, стерео;
короткий WAV дополняется тишиной до конца видео. Для этого по умолчанию выбран
быстрый **Apple AudioToolbox**. Можно выбрать прежний **FFmpeg AAC**.
При отключении копирования RU также кодируется заново.

В MP4 остаются 5 потоков: H.264-видео, RU AAC-LC первым и основным,
DE AAC-LC вторым, RU и DE переключаемые mov_text-субтитры.
Совместимый немецкий AAC-LC также копируется. Дорожки не смешиваются.
Есть faststart. Поддержка переключения субтитров зависит от плеера.

## Только звук

Выберите русскую озвучку либо конкретную дорожку исходного видео.
Можно напрямую добавить WAV, M4A, AAC, MP3 или FLAC; видео и SRT тогда не нужны.

- **AAC без перекодирования**: копирует уже существующий AAC. WAV/MP3 нельзя
  превратить в AAC без кодирования.
- **AAC 96 / 128 / 192 / 256 кбит/с**: M4A или чистый поток `.aac` (ADTS).
- **MP3 128 / 192 / 256 / 320 кбит/с**: по умолчанию **320**, CBR, LAME.

M4A удобнее для дальнейшего добавления в MP4: контейнер сохраняет точные
сведения о временной шкале и задержке кодировщика. Увеличение битрейта
не улучшает исходную запись. При нескольких дорожках исходника выбор явный.

## Очередь и проекты

В верхней панели и в меню **«Проект»** доступны **Новый проект** (⌘N),
**Открыть проект…** (⌘O), **Сохранить** (⌘S) и **Сохранить как…** (⇧⌘S).
Новый проект сначала предлагает сохранить изменения, затем очищает только
рабочую очередь и настройки — исходники и готовые файлы остаются на диске.
Проект `.olyalecture` хранит список, входные пути, настройки, папку результата,
параллельность и ссылки на завершённые результаты. Сами медиафайлы в него
не копируются: при переносе проекта исходники должны оставаться доступны.
При открытии файлы и завершённые результаты проверяются заново.
Незавершённое задание запускается с начала, с середины файла оно не продолжается.
Перед закрытием или открытием другого проекта предлагается сохранить изменения.
Разрешение заменять существующие результаты в проект не записывается.

**Авто** на этом M4 запускает до четырёх заданий. Можно выбрать 1, 2, 3 или 4.
CPU-потоки декодирования распределяются между активными видео; H.264 кодирует
медиаблок. Аудиокодек не всегда распараллеливает один файл, поэтому для звука
ускорение даёт очередь из нескольких файлов. Более высокая параллельность
не означает линейное ускорение: медиаблок и диск имеют общий предел.
Кнопка **Остановить** прерывает все активные задания и не запускает следующие.

## Проверки и сохранность файлов

Результат сначала записывается во временный файл и публикуется атомарно после
проверки кодеков, дорожек, длительности и декодирования начала, середины, конца.
Для MP3 дополнительно проверяется битрейт. Есть общий резерв свободного места
для всех параллельных заданий. При одинаковых именах по умолчанию сохраняются
копии. «Пропустить» и «Заменить» доступны отдельно; замена подтверждается при запуске.
Исходники никогда не перезаписываются. Ошибка или остановка удаляет только
временный результат текущего задания. После аварии системы он может остаться
скрытым `.olya-*.partial.*`; готовым такой файл не считается.

Журналы: `~/Library/Application Support/OlyaLectureAssembler2/Logs`.
Открываются через меню приложения **Показать журналы**.

Локальная проверка описана в [VERIFICATION.md](VERIFICATION.md). Подтверждение Android/ПК из
исходного ТЗ относится к прежней схеме дорожек; новые файлы версии 2 на этих
устройствах пока не проверялись. Проверка структуры не определяет язык речи.

## Сборка из исходников

**Собрать приложение.command** или `bash Scripts/build.sh`.
Нужны Apple Command Line Tools / Swift. Приложение локально подписано ad-hoc.

```bash
bash Scripts/test.sh
bash Scripts/test-v2.sh
build/integration-tests --full-only
python3 Scripts/check-sync.py SOURCE.mp4 RESULT.mp4 --positions 12 300 600
```

FFmpeg / FFprobe 9.0.1 и LAME 4.0 находятся в `vendor`; соответствующие исходники
и лицензии включены в приложение. Скрипт зависимостей — `Scripts/build-ffmpeg.sh`.
Иконка строится из исходного SF Symbol `play.rectangle.on.rectangle.fill`:
увеличенные бирюзовые карточки двух оттенков, белый Play, прозрачные фон и зазор.
Внешней белой обводки нет. Стандартный ICNS включает размеры 16–1024 px.
