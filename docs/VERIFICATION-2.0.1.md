# Проверка LectureMerge 2.0.1 — 3 сентября 2026

Изменён только значок приложения и номер выпуска. Выбран вариант №2:
увеличенные бирюзовые карточки двух оттенков, белый Play, прозрачные фон и зазор.
Исходники приложения в `Sources/`, медиатесты и зависимости совпадают с v2.0.0.

## Проведённые проверки

- `bash Scripts/check.sh`: структура, метаданные, сценарии, архивы зависимостей
  и проверка типов Swift прошли.
- PNG 1024 и 64 px побайтово совпадают с выбранным вариантом №2.
- `dist/v2.0.1/Сборка лекций 2.app` собран; Info.plist содержит версию 2.0.1,
  номер сборки 3 и ссылку на ресурс AppIcon.
- ICNS содержит десять стандартных представлений 16–1024 px.
- Восемь PNG-представлений после упаковки сохраняют цвета и прозрачность.
  Для маленьких представлений 16/32 px дополнительно проверена реальная
  отрисовка AppKit в bitmap: цвет и alpha совпали с исходными PNG,
  углы остались прозрачными. Проверено наличие нарисованных пикселей.
- `codesign --verify --deep --strict` для нового приложения прошёл.
- Сборка не изменила зафиксированные исходники; состав совпадает с BUILD-INFO.
- Повторный `build.sh` отказал в перезаписи `dist/v2.0.1`; хеши всех файлов
  готовой сборки после отказа остались прежними.
- SHA-256 всех 22 файлов приложения и архива старого выпуска 2.0.0 совпали
  с контрольными суммами, снятыми перед работой.

При проверке обнаружена особенность `iconutil -c iconset`: обратное извлечение
маленьких ARGB-представлений может показывать светлую кайму, которой нет
при реальной отрисовке ICNS в AppKit. Изменение premultiplication ради такого
извлечения ухудшает настоящий значок. Поэтому сохранена штатная упаковка
`iconutil`, проверенная через AppKit; экспериментальные варианты не включены.

## Архивы выпуска

`Scripts/release.py` перед публикацией проверяет версию, состав исходников,
подпись приложения, бинарные зависимости и CRC обоих ZIP. Он создаёт новый
тег и новый каталог выпуска без перезаписи существующих.

Окончательная проверка опубликованного локального выпуска:

```bash
python3 Scripts/verify-release.py v2.0.1
```

Она сверяет SHA-256, Git-тег, CRC ZIP, подпись распакованного приложения
и хеши вложенных FFmpeg/FFprobe. Результаты медиапроверок прежней версии
сохранены в [VERIFICATION.md](VERIFICATION.md) и
[VERIFICATION-2.0.md](VERIFICATION-2.0.md).
