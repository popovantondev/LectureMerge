# Проверка LectureMerge 2.0.2 — 6 сентября 2026

Исправлена проверка длительности русской озвучки. Программа сравнивает короткую
RU-дорожку с последним таймкодом RU SRT. При совпадении с допуском 0,5 с сборка
разрешена: видео сохраняется полностью, готовый AAC не растягивается и не
перекодируется. Звук длиннее видео и несовпадающая с SRT короткая дорожка
остаются на ручной проверке.

## Проверки изменения

- `Scripts/check.sh`: структура проекта и проверка типов Swift прошли.
- Полный `Scripts/test.sh`: базовые и v2-интеграционные тесты прошли.
- Синтетический комплект с видео 6 с, M4A/SRT около 1 с получил статус
  «Готова»; результат сохранил шестисекундное видео и короткий AAC без растяжения.
- Короткая дорожка с несовпадающим концом SRT получила статус «Нужна проверка».
- Дорожка длиннее видео получила отдельное предупреждение о возможной обрезке слов.
- Реальный комплект 0017 проверен без изменения исходников: видео 2871,600 с,
  M4A 2852,267 с, последний таймкод RU SRT 2852,250 с. Статус — «Готова»;
  показан хвост видео без русской речи 19,33 с и копирование AAC без перекодирования.

Проверка готового приложения, подписи, архивов и контрольных сумм выполняется
по процедуре [BUILD.md](BUILD.md) и `Scripts/verify-release.py`.
