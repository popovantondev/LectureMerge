# Changelog

[English](CHANGELOG.md) · [Deutsch](../de/CHANGELOG.md) · [Русский](../ru/CHANGELOG.md)

## 2.2.0

- Added a selectable Russian, German, and English interface. The selection is saved; the first launch follows a supported macOS language.
- Added localized app menus, queue statuses, settings, messages, bundle names, and language-specific documentation with matching screenshots.

## 2.1.0

- Added explicit New, Open Project, Save, and Save As actions in the toolbar; removed the ambiguous three-dot menu.
- Added the same project actions and keyboard shortcuts to the Project menu.
- New Project now protects unsaved changes and clears only the app queue and settings.
- Save As can create a folder for the `.olyalecture` project file.

## 2.0.2

- Allowed short Russian narration when it ends with the last Russian subtitle.
- Preserved the full video without stretching speech and copied compatible AAC without re-encoding.
- Kept longer audio and audio that does not match its SRT for manual review.
