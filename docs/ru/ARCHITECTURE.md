# Архитектура LectureMerge

[English](../en/ARCHITECTURE.md) · [Deutsch](../de/ARCHITECTURE.md) · [Русский](ARCHITECTURE.md)

LectureMerge — нативное приложение на AppKit и SwiftUI. В нём нет веб-сервера и внешних API. FFmpeg запускается локально как дочерний процесс.

| Область | Назначение |
|---|---|
| `Sources/App.swift` | Окно, меню, строки очереди и настройки экспорта |
| `Sources/Localization.swift` | Выбор языка и локализованные сообщения |
| `Sources/QueueModel.swift` | Импорт, состояние проекта, очередь, параллельность и отмена |
| `Sources/Core.swift` | Анализ FFprobe, сопоставление файлов, MP4, субтитры, проверка и безопасная запись |
| `Sources/Audio.swift` | Профили звука, AAC/MP3 и резервирование места на диске |
| `Sources/Project.swift` | JSON-формат проекта и восстановление путей |
| `Resources/*.lproj` | Русские, немецкие и английские строки приложения и метаданные |

FFprobe читает потоки и временную шкалу. Matcher сопоставляет дополнительные файлы по полному имени и проверяет комплект. Планы экспорта задают параметры FFmpeg. Неподдерживаемые сочетания выявляются до начала обработки.

У каждого активного задания есть отдельный токен отмены. Swift task group запускает не более четырёх заданий одновременно. Главный актор обновляет интерфейс; медиапроцессы выполняются отдельно. Общий резерв диска учитывает все активные результаты на одном томе.

FFmpeg сначала пишет временный файл. После проверки потоков, языков, длительности и декодирования образцов результат перемещается в целевую папку. Эксклюзивное переименование защищает режим копии от конкурентной перезаписи. Совместимый RU AAC-LC копируется без перекодирования; короткая озвучка не обрезает видео.

Файл проекта хранит локальные пути и настройки, но не медиа. При открытии готовый результат проверяется повторно. LectureMerge — отдельная программа от SRT Озвучки; она не переводит и не синтезирует речь.
