# Сборка и тестирование LectureMerge

[English](../en/BUILD.md) · [Deutsch](../de/BUILD.md) · [Русский](BUILD.md)

## Требования

Нужен Mac с Apple Silicon, macOS 14 или новее, Apple Command Line Tools, Swift, Python 3, Git и стандартные инструменты сборки macOS. Все команды выполняются из корня репозитория.

## Подготовка медиакодеков

Приложение включает FFmpeg, FFprobe и LAME. Эти сторонние бинарные файлы исключены из Git. После чистого клонирования выполните:

```bash
bash Scripts/build-ffmpeg.sh
```

Сценарий загружает закреплённые исходные архивы из `vendor/dependencies.json`, проверяет SHA-256 и собирает локальные инструменты. Это требуется для разработки и упаковки приложения, но не для запуска готовой программы.

## Проверки и тесты

```bash
bash Scripts/check.sh
bash Scripts/test.sh
```

Первая команда проверяет метаданные проекта, языковые ресурсы, сценарии и типы Swift. Вторая создаёт короткие искусственные медиафайлы в игнорируемой папке сборки и проверяет MP4, SRT, AAC, MP3, проекты, очередь и отмену через FFmpeg и аппаратный кодировщик. Эти проверки не заменяют просмотр работающего окна и проверку на реальных устройствах.

## Пробная сборка и выпуск

```bash
bash Scripts/build.sh --preview
bash Scripts/build.sh
```

Пробная сборка всегда создаёт новый каталог в `build/previews`. Выпуск создаётся в `dist/v<VERSION>`; существующий выпуск нельзя перезаписать. Сценарий включает все три языка, сведения о лицензиях, сверяет отпечаток исходников и проверяет локальную ad-hoc подпись. Apple не выполняет нотарификацию приложения.

Для языковой проверки можно запустить пробную версию с переменной `LECTURE_MERGE_LANGUAGE=en`, `de` или `ru`. Она действует только для этого процесса и не меняет сохранённый в программе выбор языка.
