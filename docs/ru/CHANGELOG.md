# История изменений

[English](../en/CHANGELOG.md) · [Deutsch](../de/CHANGELOG.md) · [Русский](CHANGELOG.md)

## 2.2.0

- Добавлен переключатель интерфейса: русский, немецкий и английский. Выбор сохраняется; при первом запуске используется поддерживаемый язык macOS.
- Локализованы меню, статусы очереди, настройки, сообщения и метаданные приложения. Для каждого языка подготовлена отдельная документация со своими скриншотами.

## 2.1.0

- В верхней панели появились явные команды «Новый», «Открыть проект», «Сохранить» и «Сохранить как»; меню с тремя точками убрано.
- Те же команды и сочетания клавиш добавлены в меню «Проект».
- Команда «Новый проект» защищает несохранённые изменения и очищает только очередь и настройки приложения.
- «Сохранить как» позволяет создать папку для файла проекта `.olyalecture`.

## 2.0.2

- Разрешена короткая русская озвучка, если она заканчивается вместе с последним русским субтитром.
- Полное видео сохраняется, речь не растягивается, совместимый AAC копируется без перекодирования.
- Длинная озвучка и несовпадение с SRT остаются на ручной проверке.
