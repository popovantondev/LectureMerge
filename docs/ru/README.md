# Руководство пользователя

[Скачать для macOS](https://github.com/popovantondev/LectureMerge/releases/tag/v2.1.0) · [Deutsch](../de/README.md) · [Русский](README.md) · [English](../en/README.md)

LectureMerge — локальная программа для macOS, которая объединяет видео лекции, русскую озвучку, оригинальный звук и субтитры в MP4. Она также экспортирует звук отдельно в AAC или MP3. Текущая версия: **2.1.0** · macOS 14+ · Apple Silicon.

## Первая сборка

1. Добавьте папку с лекциями или выберите отдельные видео и аудиофайлы.
2. Выберите строку очереди и проверьте подобранные озвучку и субтитры.
3. Выберите **«Видео MP4»** или **«Только звук»**, затем настройте результат.
4. Укажите папку результата. По умолчанию готовые файлы сохраняются в **Готовое** рядом с исходным видео.
5. Сначала запустите **Тест 30 секунд** и проверьте результат.

Строку можно удалить клавишами Backspace/Delete, кнопкой корзины или через контекстное меню. **Очистить очередь** удаляет только записи из списка; исходники и готовые файлы остаются на диске.

## Видео и звук

Разрешения видео — от 144p до 4K. **Без перекодирования** копирует совместимое видео H.264 без изменения качества. **Исходное разрешение** сохраняет размер кадра; при включённом соответствующем параметре видео всё равно перекодируется. Для изменения разрешения используется аппаратный кодировщик Apple H.264 VideoToolbox.

Совместимая русская дорожка AAC-LC в M4A/MP4 копируется в MP4 без перекодирования. WAV и несовместимые аудиофайлы кодируются в AAC-LC. Короткая озвучка допустима, если заканчивается вместе с последним русским субтитром; дальше видео идёт без русской речи. Темп речи не растягивается.

Экспорт только звука поддерживает копирование AAC, AAC 96–256 кбит/с и MP3 128–320 кбит/с. Для MP3 по умолчанию выбрано 320 кбит/с. M4A сохраняет временную привязку для последующей сборки MP4.

## Проекты и сохранность

Команды **Проект → Новый проект / Открыть проект… / Сохранить / Сохранить как…** сохраняют очередь и настройки. Файл проекта хранит пути к исходникам, но не копирует медиа.

LectureMerge работает локально, без интернета и онлайн-API. Исходные файлы не перезаписываются. Результат сначала создаётся во временном файле, а затем проверяется. Приложение имеет ad-hoc подпись и не нотарифицировано Apple.
