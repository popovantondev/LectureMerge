Installation

The steps from “First steps” in the guide, in Terminal.

$ shasum -a 256 LectureMerge-v2.2.0-macos-arm64.zip
# Compare the value with SHA256SUMS from the release
$ unzip LectureMerge-v2.2.0-macos-arm64.zip
# Ad-hoc signed, not notarized: macOS may warn on first launch
→ Add a folder or files, create the 30-second test first

Runs locally

Processing runs on your Mac with built-in FFmpeg and LAME. No account, no web server, no external API; your source files stay unchanged.
