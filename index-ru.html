LectureMerge

Объединяет видео лекции, озвучку, исходное аудио и субтитры в MP4; также экспортирует аудио.

Выпуск · 2.2.0 macOS 14+ · Apple Silicon
Скачать для macOS Исходный код Swift · AppKit Руководство ↗

Перед запускомОбработка локальная; внешний сервис не нужен. Приложение подписано ad-hoc и не нотарифицировано Apple.

Что внутри

Установка, функции, передача данных и проверка.

Установка

Шаги из «Первых шагов» руководства, в Терминале.

$ shasum -a 256 LectureMerge-v2.2.0-macos-arm64.zip
# Сверить значение с SHA256SUMS из релиза
$ unzip LectureMerge-v2.2.0-macos-arm64.zip
# Подписано ad-hoc, не нотаризовано: при первом открытии macOS может предупредить
→ Добавить папку или файлы, сначала сделать 30-секундный тест

Работает локально

Обработка идёт на вашем Mac со встроенными FFmpeg и LAME. Без аккаунта, веб-сервера и внешнего API; исходные файлы не меняются.

Проверено

  • Автоматические проверки в GitHub Actions (macOS 15): метаданные, локализация, проверка типов Swift
  • Локальные проверки по отчёту о версии 2.2.0: скрипты проверки и тестов, предварительная сборка, проверка подписи
  • Переводы RU · DE · EN проверены на полноту и параметры подстановки
  • Контрольные суммы SHA-256 (SHA256SUMS) и manifest.json в релизе
  • Версия 2.2.0 и журнал изменений

Как это работает

  1. Видео + озвучка + субтитры
  2. Проверить параметры
  3. Сохранить MP4

Первые шаги

Распакуйте архив приложения, добавьте видео, аудио и субтитры. Проверьте 30-секундный фрагмент перед полным экспортом.
